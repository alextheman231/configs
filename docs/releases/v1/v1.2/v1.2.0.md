**Status**: Released

<!-- alex-c-line-release-summary-start -->
This is a new minor release of the `@alextheman/configs` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Convert the Oxlint config into a function that returns the configuration
  - This allows the base default configuration to be used still, but it also accepts some additional option arguments to control, for example, scoping of relative import denial and which files specifically to sort object keys in.
- Fix the relative import restriction logic more generally.
  - Previously it was using groups, which didn't quite catch some relative imports. This now uses regex which defines it more rigourously.
