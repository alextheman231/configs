**Status**: Released

<!-- alex-c-line-release-summary-start -->
This is a new minor release of the `@alextheman/configs` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Use separate entrypoints for the oxfmt and oxlint configs
  - I think it's probably cleaner in general to split configs by entrypoint so that we don't end up bringing in a bunch of unrelated dependencies if, for example, we want the Oxfmt config but not the Oxlint config.

## Additional Notes

- Not doing this as a major for now as it is early days, and as mentioned before this is to be treated as an internal package in the organisation where minor releases may also be capable of breaking changes too.
